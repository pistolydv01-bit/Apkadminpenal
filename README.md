# Admin Panel Starter

Standalone Flask admin panel + JSON API.

## Run
1. Install Python 3.10+
2. `pip install -r requirements.txt`
3. `python app.py`
4. Open `http://127.0.0.1:5000`

Default demo admin:
- Username: admin
- Password: change-me-now

Change ADMIN_USERNAME and ADMIN_PASSWORD before deployment.

## Important
This starter does NOT modify or reverse-engineer the supplied APK. Your current ZIP contains only an extracted resource image, not the original Android source project. The Android app will need its original source or a deliberately rebuilt client before it can securely consume this API.
